# Automatic-Power-Factor-Correction
Python-based simulation of an Automatic Power Factor Correction system. 
⚡ Automatic Power Factor Correction (APFC) System Using Python

📌 Project Overview

This project demonstrates a Python-based simulation of an Automatic Power Factor Correction (APFC) system. It calculates the initial power factor, determines the required capacitor bank rating, and analyses power factor improvement after compensation.

🎯 Objectives

- Understand power factor correction.
- Calculate reactive power compensation.
- Simulate automatic capacitor bank selection.
- Analyse performance under different load conditions.

🛠️ Tools Used

- Python
- Google Colab
- NumPy
- Matplotlib

⚙️ Working Principle

The system calculates the reactive power required for correction and selects suitable capacitor bank steps to improve the power factor.

📊 Simulation Results

Load| Initial PF| Improved PF
10 kW| 0.70| 0.922
8 kW| 0.75| 0.991
12 kW| 0.80| 0.970

📈 Output

The simulation generates graphs comparing power factor before and after compensation.
